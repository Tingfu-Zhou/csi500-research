# Report font

D11ReportSans.ttf is a 400-weight, report-glyph subset of Noto Sans SC, renamed for this derivative. Source: https://github.com/notofonts/noto-cjk/blob/main/Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf . Licensed under the SIL Open Font License 1.1; see OFL.txt. It is embedded for portable Chinese rendering. The subset is intended for the archived report only; a substantially changed template may need a newly generated subset.
